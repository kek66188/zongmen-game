# 西游镇妖录

《西游镇妖录》是一个手机竖屏 H5 单机小游戏，开发代号仍兼容《宗门守卫战》。玩家选择孙悟空、唐僧、猪八戒、沙僧之一守关斩妖，沿西游取经路推进 1-40 关，击败中国志怪 / 西游妖怪，收集符文并邀请伙伴助战。

基础游玩只使用原生 HTML、CSS、JavaScript，不依赖后端，不需要 npm install，可直接打开 `index.html` 游玩。手动云存档是可选 Vercel Serverless 功能。

## 中国志怪妖物重绘

本阶段将怪物体系重构为原创 Canvas 绘制的中国志怪 / 西游妖怪风格，不引入图片素材、不切图、不使用外部版权资源。怪物配置集中在 `main.js` 的 `ENEMY_TYPES` / `MONSTER_BOOK`，绘制入口是 `Enemy.drawJourneyEnemy()`。

旧怪物 key 会继续兼容：`imp/small -> foxDemon`、`runner -> shrimpDemon`、`brute/giant -> boarDragon`、`shield/poison -> frogDemon`、`fire/fireling -> lampGranny`、`stone -> stoneArmor`、`flying -> wingDemon`、`mage/caster -> curseMage`、`splitter -> nineTailShade`、`split/drainer -> boneDemon`、`elite/vanguard -> bullVanguard`、`boss10/20/30/40 -> bossBlackWind/bossYellowWind/bossBoneLady/bossBullKing`。

阶段妖怪池：

- 1-10 关：狐妖、犬妖、赤虾子、猪龙、蛙妖，10 关 Boss 黑风怪。
- 11-20 关：加入灯花婆婆、石甲妖、夜叉，20 关 Boss 黄风妖王。
- 21-30 关：加入飞妖、咒师妖、水猿妖、九尾狐影，30 关 Boss 白骨夫人。
- 31-40 关：加入黑风怪卒、白骨妖、牛魔先锋，40 关 Boss 牛魔王。

怪物受击会闪白/闪金并生成粒子；冰冻、灼烧、眩晕、护盾破碎和死亡都有不同反馈。Boss 使用更大的体型、顶部金边血条、阶段刻度和出场震动提示。

## 玩法说明

- 在首页选择取经角色，点击“开始守山”进入战斗。
- 战斗中可点击右上角“速 x1 / 速 x2”切换 1 倍或 2 倍速度。
- 怪物会从屏幕上方向下移动，撞到城墙会造成伤害。
- 玩家无需移动或瞄准，角色主题技能、符文效果和伙伴助战都会按冷却自动释放。
- 斩妖获得修为，修为满后暂停并弹出三选一升级卡。
- 山门血量归零失败，坚持 120 秒守卫成功。

## 西游角色系统

首页新增“选择取经人”，四名角色都会保存到本地存档：

- 孙悟空：高爆发 / 连击 / 分身。初始“金箍棒影、筋斗雷”，暴击率更高，每隔一段时间触发“残影追击”。
- 唐僧：辅助 / 控制 / 回复。初始“紧箍梵音、禅杖佛光”，冷却更快，更容易获得高品质升级，并缓慢回复结界。
- 猪八戒：肉盾 / 范围 / 控场。初始“九齿钉耙横扫、饕餮吞势”，结界血量更高并降低受击伤害。
- 沙僧：均衡 / 持续输出 / 水系减速。初始“月牙铲斩、流沙困阵”，减速和阵法持续伤害更强。

角色拥有简化 Canvas 肖像、定位说明、初始技能和胜场/等级记录。战斗 HUD 会显示当前主角色。

## 伙伴助战

通关第 10、20、30 关后会弹出“邀请伙伴助战”界面。已经作为主角的角色不会重复出现，最多形成 1 名主角 + 3 名伙伴阵容。

伙伴会自动释放专属技能：

- 孙悟空伙伴：分身突袭，金红分身冲击妖群。
- 唐僧伙伴：佛光普照，回复结界并短暂提升全体技能伤害。
- 猪八戒伙伴：钉耙震地，范围伤害并震退城门前妖群。
- 沙僧伙伴：流沙牵引，生成流沙旋涡减速并牵引妖怪。

## 符文系统

首页新增“符文玉匣”。玩家可拥有多枚符文，并装备最多 3 枚。通关任意试炼会获得随机符文，Boss 关更容易掉落高品质符文。

符文品质：凡品、良品、上品、灵品。

当前符文类型：

- 攻击符文：狂击符、穿透符、爆炎符、连雷符。
- 守御符文：金钟符、护体符、结界符。
- 机缘符文：聚灵符、招财符、时轮符。

符文效果会直接进入战斗，例如提高暴击率、主武器穿透、范围法术、天威弹射、结界血量、受击减伤、修为获取、灵石奖励和冷却缩短。

## 妖怪图鉴与成就

首页新增“妖怪图鉴”和“取经成就”。

- 妖怪图鉴会记录已经遭遇过的中国志怪 / 西游妖怪，并显示定位与解锁关卡。
- 成就系统记录首次通关第 10/20/30/40 关、累计斩妖 1000、获得多枚高品质符文等目标。

## 第一关平衡

第一关时长仍然是 120 秒，不是 180 秒。第一关最大场上怪物数量仍然是 80。

阶段节奏：

- 0 秒：妖潮初现
- 20 秒：妖气渐浓
- 40 秒：巨妖来袭
- 70 秒：妖潮汹涌
- 95 秒：最后冲击
- 110 秒：宗门决战

关卡时长、最大怪物数、怪物刷新节奏、阶段提示等都通过 `LEVEL_CONFIG.level1` 配置管理，后续增加第二关、第三关时应继续扩展 `LEVEL_CONFIG`，不要在逻辑里写死时长。

## 40 关试炼

首页“选择试炼”扩展为 40 关，按顺序通关解封。默认选择当前已解封的最高试炼，未解封试炼点击时会提示先通关上一关。

关卡按西游章节分为四段：

- 第 1-10 关：花果山妖乱，狐妖、犬妖、赤虾子、猪龙、蛙妖逐步出现，第 10 关 Boss 黑风怪。
- 第 11-20 关：高老庄异闻，灯花婆婆、石甲妖、夜叉混入妖潮，第 20 关 Boss 黄风妖王。
- 第 21-30 关：流沙河妖雾，飞妖、咒师妖、水猿妖、九尾狐影压阵，第 30 关 Boss 白骨夫人。
- 第 31-40 关：火焰山终劫，黑风怪卒、白骨妖、牛魔先锋和高压妖潮频繁出现，第 40 关 Boss 牛魔王。

关卡配置由 `LEVEL_CONFIG` 统一生成和管理。每关包含编号、名称、推荐阶段、持续时间、怪物倍率、伤害倍率、刷新倍率、可出现怪物、精英概率、Boss 配置、阶段提示和奖励倍率。第一关仍保留新手平衡：120 秒、最大怪物数 80。

Boss 关：

- 第 10 关：黑风怪，低速靠近并周期性召唤小妖。
- 第 20 关：黄风妖王，带风压光环并召唤厚血妖潮。
- 第 30 关：白骨夫人，召唤咒师妖并有阶段护盾。
- 第 40 关：牛魔王，70%/40%/20% 血量触发不同阶段能力，击败后显示“万妖退散，山门永固”。

每个试炼独立保存最佳斩妖、最高境界、最长存活和镇守次数。通关第 N 关会解封第 N+1 关，已通关关卡可以重复挑战。

毒雾妖死亡后的毒雾只有贴近山门结界时才会腐蚀城墙，远处毒雾只作为视觉和战场压力提示，不会隔空扣血。

灵石结算仍使用原公式，再乘以当前试炼奖励倍率：

```javascript
最终灵石 = Math.floor((斩妖数 + Math.floor(存活秒数 / 10) * 2 + 通关奖励) * rewardMultiplier)
```

宝石碎晶奖励会随试炼追加，越后期试炼额外碎晶越多：

- 第 1-2 关：当前规则不变。
- 第 3-4 关：通关额外 +1 随机碎晶。
- 第 5-6 关：通关额外 +2 随机碎晶。
- 第 7-8 关：通关额外 +3 随机碎晶。
- 第 9 关：通关额外 +4 随机碎晶。
- 第 10 关后：Boss/高阶试炼会继续提高额外碎晶奖励，第 40 关通关奖励最高。

## 青绿水墨 UI 与特效

当前视觉风格调整为“青绿水墨国风修仙手游 UI”：

- 页面主色为青绿、湖绿、玉白和淡金，整体更清透柔和，不再是暗黑厚重风格。
- HTML UI 使用玉质半透明面板、玻璃拟态、细金边、圆形玉佩技能图标和轻柔云雾背景。
- 首页、HUD、试炼选择、宗门养成、升级三选一和结算页统一为青绿玉白手游面板风格。
- Canvas 绘制青绿色渐变、云雾、水波、远山、月光、玉阶山门和半透明结界感城墙。
- 背景妖气会根据 `LEVEL_CONFIG.level1.duration` 计算的进度逐步增强。
- 山门低血时裂纹更明显，受击时会闪烁。
- 怪物外观使用妖物剪影、红眼、妖气、护盾纹和国风血条表现；小妖、巨妖、疾行妖、护盾妖以及后续新增妖物都有不同轮廓和反馈。
- 5 类底层技能会按当前主角显示为不同主题：主武器、范围法术、镇妖控制、天威雷法和护山法阵。
- 命中、死亡、护盾破裂、回血、灵石结算都有粒子或文字反馈。
- 升级卡片为玉质半透明卡片，左侧圆形技能图标，稀有和史诗有不同发光表现。

背景、特效和 UI 主要使用 Canvas 几何图形、CSS 渐变、阴影和动画完成；妖怪主体使用本地原创裁切 PNG sprite，没有引用外部图片素材，也没有引入外部字体文件。

## 音效与震动

首页提供“音效：开/关”按钮，状态会保存到 localStorage 存档中。

音效使用 Web Audio API 实时生成，不引用外部音频文件。当前包含：

- 按钮点击
- 主武器命中
- 范围法术爆发
- 镇妖控制命中
- 天威雷法命中
- 城墙受击
- 升级选择
- 游戏胜利
- 游戏失败

如果手机浏览器支持 `navigator.vibrate`，城墙受击、升级选择、天威雷法命中、胜利/失败会触发轻量震动。浏览器不支持时会自动跳过，不影响游戏。

## 战斗加速

战斗界面右上角提供“速 x1 / 速 x2”按钮。2 倍速会让关卡倒计时、怪物移动、刷新节奏、技能冷却、弹道、粒子、状态持续时间、Boss 计时和区域效果都按游戏内时间加快。暂停、升级三选一、结算和 UI 点击不受影响。

速度选择会使用单独 localStorage key `zmsw_timeScale` 保存，只接受 `1` 或 `2`。

## 性能限制

- 游戏循环仍使用 `requestAnimationFrame`。
- 第一关最大怪物数量保持 80。
- 普通战斗粒子上限 250，2 倍速时收敛到 200。
- 背景灵气粒子上限 40。
- 音效和震动做了节流，避免高频触发造成卡顿。
- `DEBUG_BALANCE` 默认关闭，不会持续输出控制台日志。

## 灵石系统

局内变量仍使用 `coins`，UI 中显示为“灵石”。每局结束后会根据表现结算局外灵石：

- 基础灵石：斩妖数 * 1
- 存活奖励：`Math.floor(存活秒数 / 10) * 2`
- 通关奖励：守卫成功额外 +50

灵石会保存到 localStorage，并显示在首页、宗门养成页和结算页。

## 宝石 / 灵石镶嵌

宝石在 UI 中表现为“灵石镶嵌”，每种都有独立等级和碎晶数量：

- 攻击宝石：每级所有技能伤害 +3%
- 冷却宝石：每级所有技能冷却 -2%，最多 -40%
- 城墙宝石：每级山门最大血量 +10
- 暴击宝石：每级暴击率 +2%，最多 50%
- 经验宝石：每级斩妖修为 +5%

宝石碎晶来源：

- 每 30 斩妖，至少获得 1 个随机宝石碎晶。
- 通关额外获得 2 个随机宝石碎晶。

## 功法修炼

天赋在 UI 中表现为“功法修炼”，使用灵石升级，当前实现 8 个天赋：

- 兵器精通：每级主武器伤害 +5%，最高 10 级
- 法术精通：每级范围法术效果 +4%，最高 10 级
- 镇妖控制：每级控制效果 +3%，最高 10 级
- 天威感应：每级天威伤害 +5%，最高 10 级
- 阵法修行：每级阵法伤害 +5%，最高 10 级
- 城墙加固：每级山门最大血量 +15，最高 10 级
- 战斗领悟：每级修为获取 +3%，最高 10 级
- 起始灵力：每级开局修为 +5，最高 5 级

## 本地存档

所有局外进度使用 localStorage 保存，存档 key 为：

```javascript
zongmen_guardian_save_v1
```

存档内容包括灵石/金币、仙玉、宝石等级与碎片、天赋等级、当前角色、角色等级/胜场、伙伴邀请、符文拥有/装备、妖怪图鉴、成就、最高斩妖、最长存活、最高境界、最高通关关卡、累计斩妖、累计灵石、通关次数、总游玩次数、音效开关，以及 `levels` 字段。

`levels` 会记录 1-40 关每个试炼是否解封、是否镇守成功、最高斩妖、最高境界、最长存活和镇守次数。老存档如果没有 `levels` 字段会自动补齐，不会重置灵石、宝石、功法或音效设置；如果老存档已有通关次数，会默认标记第 1 关已镇守并解封第 2 关。

## 如何重置存档

在首页点击“重置存档”，二次确认后会清空灵石、宝石、功法和历史记录，并刷新界面到默认进度。

## 如何本地运行

可以直接用浏览器打开 `index.html` 游玩。

也可以在当前目录启动静态服务器：

```bash
python -m http.server 8000
```

然后在电脑浏览器访问：

```text
http://localhost:8000
```

## 手机访问

手机和电脑连接同一个局域网后，在手机浏览器访问：

```text
http://电脑局域网IP:8000
```

例如电脑局域网 IP 是 `192.168.2.75`，则访问：

```text
http://192.168.2.75:8000
```

## 测试高阶关卡

正常流程需要按顺序通关解封。开发调试时可以在浏览器控制台临时解锁指定关卡：

```javascript
const save = JSON.parse(localStorage.getItem("zongmen_guardian_save_v1"));
for (let i = 1; i <= 40; i += 1) {
  save.levels[`level${i}`].unlocked = true;
}
localStorage.setItem("zongmen_guardian_save_v1", JSON.stringify(save));

```

## localStorage 存档说明

本游戏使用浏览器 `localStorage` 保存局外进度。同一个浏览器、同一个网址下，刷新页面、关闭网页后重新打开，存档都会保留。更换浏览器、更换手机、使用无痕模式、清理浏览器数据，都会导致本地存档不可见或丢失。

注意：本地测试地址 `http://localhost:8000/` 和 GitHub Pages 地址 `https://kek66188.github.io/zongmen-game/` 属于不同网址，浏览器会分别保存两份 localStorage，存档不会互通。

当前仍兼容旧主存档 key：

```text
zongmen_guardian_save_v1
```

同时会把关键数据同步保存到统一 key：

```text
zmsw_spiritStone
zmsw_jade
zmsw_highestClearedLevel
zmsw_selectedLevel
zmsw_bestKills
zmsw_bestSurvivalTime
zmsw_highestPlayerLevel
zmsw_clearCount
zmsw_finalCleared
zmsw_upgrades
zmsw_redeemedCodes
zmsw_lastDailyRewardDate
zmsw_timeScale
zmsw_totalRechargeTest
zmsw_saveVersion
```

首页提供“存档信息”按钮，可查看 localStorage 是否可用、灵石、仙玉、最高通关、最高解锁、宗门强化总等级、速度设置和当前存档版本。

新增角色、伙伴、符文、图鉴和成就数据都保存在主存档 `zongmen_guardian_save_v1` 中，云存档上传时也会一并导出。

## 手动云存档

游戏新增“手动云存档”功能，不需要账号、手机号或密码。玩家在“存档信息”面板里点击“上传云存档”，服务端会返回一个类似 `ZM-8F3K-29D7` 的存档码。换手机或清缓存后，在同一面板输入存档码并点击“读取云存档”，确认覆盖本地进度后即可恢复。

云存档 API：

```text
POST /api/save
GET  /api/load?code=ZM-XXXX-XXXX
GET  /api/health
```

云端存储使用 Vercel KV / Upstash Redis REST API。需要在 Vercel 项目环境变量里配置：

```text
KV_REST_API_URL
KV_REST_API_TOKEN
```

# 本次更新：西游角色、宗门、伙伴分工

局外成长现在分成四层：

- 宗门养成：消耗灵石升级，所有主角共享，负责山门血量、通用伤害、冷却、收益等基础盘。

- 伙伴助战：第 10 / 20 / 30 关通关后各获得 1 次伙伴邀请机会，可邀请未出战的西游角色加入助战。伙伴使用灵石升级助战等级，只负责周期性自动释放支援技能。

- 孙悟空：高爆发、暴击、连击、分身。初始技能为金箍棒影、毫毛分身；被动提供暴击率、暴击伤害和残影追击。

- 沙僧：均衡、持续伤害、减速、控场。初始技能为月牙铲斩、流沙困阵；被动提高减速、持续伤害和控制持续时间。

角色经验公式在 `main.js` 的 `SaveManager.addRunResult()` 中：

```javascript
heroExpGain = kills * 2 + currentLevel * 20;
if (victory) heroExpGain += 100 + currentLevel * 10;
if (currentLevel % 10 === 0 && victory) heroExpGain += 150;
```

角色升级需求在 `getHeroExpNeed()` 中：

```javascript
Math.floor(100 * Math.pow(1.18, heroLevel - 1))
```

每 10 级需要突破，突破消耗在 `getHeroBreakthroughCost()` 中：

```javascript
1000 * breakthroughStage * breakthroughStage
```

## 本次更新：妖怪图鉴插画化

妖怪图鉴不再使用小圆形头像图标，改为每张卡片左侧的大尺寸妖怪插画展示区。当前版本已接入本地原创生成 PNG sprite，素材由 `tools/slice_monsters.py` 从 `assets/source/monster-gallery.png` 裁切到 `assets/monsters/`。绘制入口仍然是 `main.js` 的 `drawMonsterIllustration(ctx, key, x, y, scale, mode)`，优先使用 `ctx.drawImage()`，加载失败时回退到 Canvas 手绘占位。
