# 宗门守卫战

《宗门守卫战》是一个手机竖屏 H5 单机小游戏。玩家守护底部宗门山门，技能会自动施放，击败从上方来袭的妖物获得修为，突破境界后从三张神通卡中选择一项强化，坚持 120 秒即可守住第一关。

项目只使用原生 HTML、CSS、JavaScript，不依赖后端，不需要 npm install，可直接打开 `index.html` 游玩。

## 玩法说明

- 点击“开始守卫”进入战斗。
- 战斗中可点击右上角“速 x1 / 速 x2”切换 1 倍或 2 倍速度。
- 怪物会从屏幕上方向下移动，撞到城墙会造成伤害。
- 玩家无需移动或瞄准，飞剑、火符、冰符、天雷、剑阵都会按冷却自动释放。
- 斩妖获得修为，修为满后暂停并弹出三选一升级卡。
- 山门血量归零失败，坚持 120 秒守卫成功。

## 第一关平衡

第一关时长仍然是 120 秒，不是 180 秒。第一关最大场上怪物数量仍然是 80。

阶段节奏：

- 0 秒：妖潮初现
- 20 秒：妖气渐浓
- 40 秒：巨妖来袭
- 70 秒：妖潮汹涌
- 95 秒：最后冲击
- 110 秒：宗门决战

关卡时长、最大怪物数、怪物刷新节奏、阶段提示等都通过 `LEVEL_CONFIG.level1` 配置管理，后续增加第二关、第三关时应继续扩展 `LEVEL_CONFIG`，不要在逻辑里写死时长。

## 40 关试炼

首页“选择试炼”扩展为 40 关，按顺序通关解封。默认选择当前已解封的最高试炼，未解封试炼点击时会提示先通关上一关。

关卡按修仙阶段分为四段：

- 第 1-10 关：炼气试炼，保留小妖、疾行妖、巨妖、护盾妖为主，第 10 关有 Boss 黑角妖将。
- 第 11-20 关：筑基妖潮，加入毒雾妖、石甲妖、妖火童子、夜叉，第 20 关有 Boss 筑基妖帅。
- 第 21-30 关：金丹魔影，加入飞妖、咒师妖、玄甲巨妖、分裂妖，第 30 关有 Boss 金丹魔修。
- 第 31-40 关：元婴大劫，加入吸灵妖、妖王先锋，第 40 关为万妖王终战。

关卡配置由 `LEVEL_CONFIG` 统一生成和管理。每关包含编号、名称、推荐阶段、持续时间、怪物倍率、伤害倍率、刷新倍率、可出现怪物、精英概率、Boss 配置、阶段提示和奖励倍率。第一关仍保留新手平衡：120 秒、最大怪物数 80。

Boss 关：

- 第 10 关：黑角妖将，低速靠近并周期性召唤小妖。
- 第 20 关：筑基妖帅，带速度光环并召唤护盾妖。
- 第 30 关：金丹魔修，近身压迫、召唤咒师妖并有阶段护盾。
- 第 40 关：万妖王，70%/40%/20% 血量触发不同阶段能力，击败后显示“万妖退散，山门永固”。

每个试炼独立保存最佳斩妖、最高境界、最长存活和镇守次数。通关第 N 关会解封第 N+1 关，已通关关卡可以重复挑战。

毒雾妖死亡后的毒雾只有贴近山门结界时才会腐蚀城墙，远处毒雾只作为视觉和战场压力提示，不会隔空扣血。

灵石结算仍使用原公式，再乘以当前试炼奖励倍率：

```javascript
最终灵石 = Math.floor((斩妖数 + Math.floor(存活秒数 / 10) * 2 + 通关奖励) * rewardMultiplier)
```

宝石碎晶奖励会随试炼追加，越后期试炼额外碎晶越多：

- 第 1-2 关：当前规则不变。
- 第 3-4 关：通关额外 +1 随机碎晶。
- 第 5-6 关：通关额外 +2 随机碎晶。
- 第 7-8 关：通关额外 +3 随机碎晶。
- 第 9 关：通关额外 +4 随机碎晶。
- 第 10 关后：Boss/高阶试炼会继续提高额外碎晶奖励，第 40 关通关奖励最高。

## 青绿水墨 UI 与特效

当前视觉风格调整为“青绿水墨国风修仙手游 UI”：

- 页面主色为青绿、湖绿、玉白和淡金，整体更清透柔和，不再是暗黑厚重风格。
- HTML UI 使用玉质半透明面板、玻璃拟态、细金边、圆形玉佩技能图标和轻柔云雾背景。
- 首页、HUD、试炼选择、宗门养成、升级三选一和结算页统一为青绿玉白手游面板风格。
- Canvas 绘制青绿色渐变、云雾、水波、远山、月光、玉阶山门和半透明结界感城墙。
- 背景妖气会根据 `LEVEL_CONFIG.level1.duration` 计算的进度逐步增强。
- 山门低血时裂纹更明显，受击时会闪烁。
- 怪物外观使用妖物剪影、红眼、妖气、护盾纹和国风血条表现；小妖、巨妖、疾行妖、护盾妖以及后续新增妖物都有不同轮廓和反馈。
- 5 种技能拥有不同国风法术特效：青白仙剑剑气、淡金火符、玉白冰环、青白天雷、青色剑阵。
- 命中、死亡、护盾破裂、回血、灵石结算都有粒子或文字反馈。
- 升级卡片为玉质半透明卡片，左侧圆形技能图标，稀有和史诗有不同发光表现。

所有美术都使用 Canvas 几何图形、CSS 渐变、阴影和动画完成，没有引用外部图片素材，也没有引入外部字体文件。

## 音效与震动

首页提供“音效：开/关”按钮，状态会保存到 localStorage 存档中。

音效使用 Web Audio API 实时生成，不引用外部音频文件。当前包含：

- 按钮点击
- 飞剑命中
- 火符爆炸
- 冰符命中
- 天雷命中
- 城墙受击
- 升级选择
- 游戏胜利
- 游戏失败

如果手机浏览器支持 `navigator.vibrate`，城墙受击、升级选择、天雷命中、胜利/失败会触发轻量震动。浏览器不支持时会自动跳过，不影响游戏。

## 战斗加速

战斗界面右上角提供“速 x1 / 速 x2”按钮。2 倍速会让关卡倒计时、怪物移动、刷新节奏、技能冷却、弹道、粒子、状态持续时间、Boss 计时和区域效果都按游戏内时间加快。暂停、升级三选一、结算和 UI 点击不受影响。

速度选择会使用单独 localStorage key `zmsw_timeScale` 保存，只接受 `1` 或 `2`。

## 性能限制

- 游戏循环仍使用 `requestAnimationFrame`。
- 第一关最大怪物数量保持 80。
- 普通战斗粒子上限 250，2 倍速时收敛到 200。
- 背景灵气粒子上限 40。
- 音效和震动做了节流，避免高频触发造成卡顿。
- `DEBUG_BALANCE` 默认关闭，不会持续输出控制台日志。

## 灵石系统

局内变量仍使用 `coins`，UI 中显示为“灵石”。每局结束后会根据表现结算局外灵石：

- 基础灵石：斩妖数 * 1
- 存活奖励：`Math.floor(存活秒数 / 10) * 2`
- 通关奖励：守卫成功额外 +50

灵石会保存到 localStorage，并显示在首页、宗门养成页和结算页。

## 宝石 / 灵石镶嵌

宝石在 UI 中表现为“灵石镶嵌”，每种都有独立等级和碎晶数量：

- 攻击宝石：每级所有技能伤害 +3%
- 冷却宝石：每级所有技能冷却 -2%，最多 -40%
- 城墙宝石：每级山门最大血量 +10
- 暴击宝石：每级暴击率 +2%，最多 50%
- 经验宝石：每级斩妖修为 +5%

宝石碎晶来源：

- 每 30 斩妖，至少获得 1 个随机宝石碎晶。
- 通关额外获得 2 个随机宝石碎晶。

## 功法修炼

天赋在 UI 中表现为“功法修炼”，使用灵石升级，当前实现 8 个天赋：

- 强化飞剑：每级飞剑伤害 +5%，最高 10 级
- 火符精通：每级火符爆炸范围 +4%，最高 10 级
- 冰符精通：每级冰符减速效果 +3%，最高 10 级
- 天雷精通：每级天雷伤害 +5%，最高 10 级
- 剑阵精通：每级剑阵伤害 +5%，最高 10 级
- 城墙加固：每级山门最大血量 +15，最高 10 级
- 战斗领悟：每级修为获取 +3%，最高 10 级
- 起始灵力：每级开局修为 +5，最高 5 级

## 本地存档

所有局外进度使用 localStorage 保存，存档 key 为：

```javascript
zongmen_guardian_save_v1
```

存档内容包括灵石/金币、宝石等级与碎片、天赋等级、最高斩妖、最长存活、最高境界、最高通关关卡、累计斩妖、累计灵石、通关次数、总游玩次数、音效开关，以及新增的 `levels` 字段。

`levels` 会记录 1-40 关每个试炼是否解封、是否镇守成功、最高斩妖、最高境界、最长存活和镇守次数。老存档如果没有 `levels` 字段会自动补齐，不会重置灵石、宝石、功法或音效设置；如果老存档已有通关次数，会默认标记第 1 关已镇守并解封第 2 关。

## 如何重置存档

在首页点击“重置存档”，二次确认后会清空灵石、宝石、功法和历史记录，并刷新界面到默认进度。

## 如何本地运行

可以直接用浏览器打开 `index.html` 游玩。

也可以在当前目录启动静态服务器：

```bash
python -m http.server 8000
```

然后在电脑浏览器访问：

```text
http://localhost:8000
```

## 手机访问

手机和电脑连接同一个局域网后，在手机浏览器访问：

```text
http://电脑局域网IP:8000
```

例如电脑局域网 IP 是 `192.168.2.75`，则访问：

```text
http://192.168.2.75:8000
```

## 测试高阶关卡

正常流程需要按顺序通关解封。开发调试时可以在浏览器控制台临时解锁指定关卡：

```javascript
const save = JSON.parse(localStorage.getItem("zongmen_guardian_save_v1"));
for (let i = 1; i <= 40; i += 1) {
  save.levels[`level${i}`].unlocked = true;
}
localStorage.setItem("zongmen_guardian_save_v1", JSON.stringify(save));
location.reload();
```

## localStorage 存档说明

本游戏使用浏览器 `localStorage` 保存局外进度。同一个浏览器、同一个网址下，刷新页面、关闭网页后重新打开，存档都会保留。更换浏览器、更换手机、使用无痕模式、清理浏览器数据，都会导致本地存档不可见或丢失。

注意：本地测试地址 `http://localhost:8000/` 和 GitHub Pages 地址 `https://kek66188.github.io/zongmen-game/` 属于不同网址，浏览器会分别保存两份 localStorage，存档不会互通。

当前仍兼容旧主存档 key：

```text
zongmen_guardian_save_v1
```

同时会把关键数据同步保存到统一 key：

```text
zmsw_spiritStone
zmsw_jade
zmsw_highestClearedLevel
zmsw_selectedLevel
zmsw_bestKills
zmsw_bestSurvivalTime
zmsw_highestPlayerLevel
zmsw_clearCount
zmsw_finalCleared
zmsw_upgrades
zmsw_redeemedCodes
zmsw_lastDailyRewardDate
zmsw_timeScale
zmsw_totalRechargeTest
zmsw_saveVersion
```

首页提供“存档信息”按钮，可查看 localStorage 是否可用、灵石、仙玉、最高通关、最高解锁、宗门强化总等级、速度设置和当前存档版本。

## 手动云存档

游戏新增“手动云存档”功能，不需要账号、手机号或密码。玩家在“存档信息”面板里点击“上传云存档”，服务端会返回一个类似 `ZM-8F3K-29D7` 的存档码。换手机或清缓存后，在同一面板输入存档码并点击“读取云存档”，确认覆盖本地进度后即可恢复。

云存档 API：

```text
POST /api/save
GET  /api/load?code=ZM-XXXX-XXXX
GET  /api/health
```

云端存储使用 Vercel KV / Upstash Redis REST API。需要在 Vercel 项目环境变量里配置：

```text
KV_REST_API_URL
KV_REST_API_TOKEN
```

如果没有配置环境变量，接口会返回：

```json
{
  "ok": false,
  "error": "云存档服务未配置 KV_REST_API_URL / KV_REST_API_TOKEN"
}
```

GitHub Pages 只能托管静态文件，不能运行 `api/save.js`、`api/load.js`、`api/health.js` 这些 Serverless Functions。因此纯 GitHub Pages 地址仍然可以正常游玩和使用本地 localStorage 存档，但云存档会提示“云存档服务未启用，请部署到 Vercel 后使用。”朋友要使用云存档，应访问 Vercel 部署后的游戏地址。

Vercel 部署步骤：

```bash
vercel
```

或在 Vercel 控制台导入 GitHub 仓库 `kek66188/zongmen-game`，然后在 Project Settings -> Environment Variables 添加 `KV_REST_API_URL` 和 `KV_REST_API_TOKEN`，重新部署。

测试云存档：

1. 打开 Vercel 部署地址。
2. 进入“存档信息”。
3. 点击“上传云存档”，记录返回的 `ZM-XXXX-XXXX`。
4. 换浏览器或清理本地存档。
5. 输入存档码，点击“读取云存档”。
6. 确认覆盖后刷新页面，检查灵石、关卡和宗门强化是否恢复。

然后在首页选择第 10、20、30、40 关，分别验证黑角妖将、筑基妖帅、金丹魔修和万妖王。

如果以后需要做账号同步，需要新增后端服务、用户注册/登录、数据库、存档上传/下载接口和防作弊校验。
