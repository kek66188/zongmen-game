# 西游镇妖录

《西游镇妖录》是一个手机竖屏 H5 单机小游戏，开发代号仍兼容《宗门守卫战》。玩家选择孙悟空、唐僧、猪八戒、沙僧之一守关斩妖，沿西游取经路推进 1-81 关，对应“九九八十一难”，击败中国志怪 / 西游妖怪，收集符文、法宝并邀请伙伴助战。

基础游玩只使用原生 HTML、CSS、JavaScript，不依赖后端，不需要 npm install，可直接打开 `index.html` 游玩。手动云存档是可选 Vercel Serverless 功能。

## 中国志怪妖物重绘

当前怪物体系使用项目内原创 PNG sprite 表现中国志怪 / 西游妖怪风格，不引用外部版权资源。怪物配置集中在 `main.js` 的 `ENEMY_TYPES` / `MONSTER_BOOK`，素材绑定集中在 `MONSTER_SPRITES`，战斗和图鉴绘制入口是 `drawMonsterIllustration()`，会优先走 `ctx.drawImage()`。

旧怪物 key 会继续兼容：`imp/small -> foxDemon`、`runner -> shrimpDemon`、`brute/giant -> boarDragon`、`shield/poison -> frogDemon`、`fire/fireling -> lampGranny`、`stone -> stoneArmor`、`flying -> wingDemon`、`mage/caster -> curseMage`、`splitter -> nineTailShade`、`split/drainer -> boneDemon`、`elite/vanguard -> bullVanguard`，旧 Boss key 会映射到当前 81 关章节 Boss。

阶段妖怪池：

- 1-27 关：狐妖、犬妖、赤虾子、猪龙、蛙妖为主，逐步加入灯花婆婆、石甲妖、夜叉。
- 28-54 关：飞妖、咒师妖、水猿妖、九尾狐影混入，怪物组合开始成型。
- 55-81 关：黑风怪卒、白骨妖、牛魔先锋和精英妖潮频繁出现。
- 每章第 9 关为 Boss 关：9/18/27/36/45/54/63/72/81 分别对应章节妖王。

怪物受击会闪白/闪金并生成粒子；冰冻、灼烧、眩晕、护盾破碎和死亡都有不同反馈。Boss 使用更大的体型、顶部金边血条、阶段刻度和出场震动提示。黑风怪、黄风妖王、白骨夫人、牛魔王为专属 Canvas 绘制造型，不再复用普通小怪素材。

## 玩法说明

- 在首页选择取经角色，点击“开始守山”进入战斗。
- 战斗中可点击右上角“速 x1 / 速 x2”切换 1 倍或 2 倍速度。
- 怪物会从屏幕上方向下移动，撞到城墙会造成伤害。
- 玩家无需移动或瞄准，角色主题技能、符文效果和伙伴助战都会按冷却自动释放。
- 斩妖获得修为，修为满后暂停并弹出三选一升级卡。
- 山门血量归零失败，坚持当前关卡配置时长守卫成功；第 81 关需要在终劫时间内击败牛魔王。

## 西游角色系统

首页新增“选择取经人”，四名角色都会保存到本地存档：

- 孙悟空：高爆发 / 连击 / 分身。初始“金箍棒影、筋斗雷”，暴击率更高，每隔一段时间触发“残影追击”。
- 唐僧：辅助 / 控制 / 回复。初始“紧箍梵音、禅杖佛光”，冷却更快，更容易获得高品质升级，并缓慢回复结界。
- 猪八戒：肉盾 / 范围 / 控场。初始“九齿钉耙横扫、饕餮吞势”，结界血量更高并降低受击伤害。
- 沙僧：均衡 / 持续输出 / 水系减速。初始“月牙铲斩、流沙困阵”，减速和阵法持续伤害更强。

角色拥有简化 Canvas 肖像、定位说明、初始技能和胜场/等级记录。战斗 HUD 会显示当前主角色。

## 伙伴助战

通关第 9、27、45 关后会弹出“邀请伙伴助战”界面。已经作为主角的角色不会重复出现，最多形成 1 名主角 + 3 名伙伴阵容。

伙伴会自动释放专属技能：

- 孙悟空伙伴：分身突袭，金红分身冲击妖群。
- 唐僧伙伴：佛光普照，回复结界并短暂提升全体技能伤害。
- 猪八戒伙伴：钉耙震地，范围伤害并震退城门前妖群。
- 沙僧伙伴：流沙牵引，生成流沙旋涡减速并牵引妖怪。

## 符文系统

首页新增“符文玉匣”。玩家可拥有多枚符文，初始可装备 3 枚；通关第 36 关解锁第 4 个符文槽，通关第 63 关解锁第 5 个符文槽。通关任意试炼会获得随机符文，Boss 关更容易掉落高品质符文。

符文品质：凡品、良品、上品、灵品。

当前符文类型：

- 攻击符文：狂击符、穿透符、爆炎符、连雷符。
- 守御符文：金钟符、护体符、结界符。
- 机缘符文：聚灵符、招财符、时轮符。

符文效果会直接进入战斗，例如提高暴击率、主武器穿透、范围法术、天威弹射、结界血量、受击减伤、修为获取、灵石奖励和冷却缩短。

## 妖怪图鉴与成就

首页新增“妖怪图鉴”和“取经成就”。

- 妖怪图鉴会记录已经遭遇过的中国志怪 / 西游妖怪，并显示定位与解锁关卡。
- 成就系统记录章节 Boss、九九终劫、累计斩妖 1000、获得多枚高品质符文等目标。

## 第一关平衡

第一关时长仍然是 120 秒，不是 180 秒。第一关最大场上怪物数量仍然是 80。

阶段节奏：

- 0 秒：妖潮初现
- 20 秒：妖气渐浓
- 40 秒：巨妖来袭
- 70 秒：妖潮汹涌
- 95 秒：最后冲击
- 110 秒：山门决战

关卡时长、最大怪物数、怪物刷新节奏、阶段提示等都通过 `LEVEL_CONFIG.level1` 配置管理，后续增加第二关、第三关时应继续扩展 `LEVEL_CONFIG`，不要在逻辑里写死时长。

## 九九八十一难主线

首页“选择试炼”扩展为 81 关，按顺序通关解封。默认选择当前已解封的最高试炼，未解封试炼点击时会提示先通关上一关。本体验版为了让好友获得完整新手流程，旧版本本地进度会在首次打开新版时自动清档，新进度从第 1 关开始重新保存。

9 个章节，每章 9 关：

- 第 1 章：花果山妖乱，1-9 关，Boss 黑风前锋。
- 第 2 章：黑风山迷雾，10-18 关，Boss 黑风怪。
- 第 3 章：高老庄异闻，19-27 关，Boss 高老庄妖首。
- 第 4 章：黄风岭劫难，28-36 关，Boss 黄风妖王。
- 第 5 章：流沙河妖潮，37-45 关，Boss 流沙河大妖。
- 第 6 章：白骨岭幻境，46-54 关，Boss 白骨夫人。
- 第 7 章：火云洞红焰，55-63 关，Boss 红孩儿。
- 第 8 章：女儿国迷阵，64-72 关，Boss 蝎子精 / 百眼魔君。
- 第 9 章：火焰山终劫，73-81 关，Boss 牛魔王。

关卡配置由 `LEVEL_CONFIG` / `LEVEL_LIST` 统一生成，`MAX_MAIN_LEVEL = 81`。每关包含编号、名称、章节、持续时间、怪物倍率、伤害倍率、刷新倍率、可出现怪物、精英概率、Boss 配置、阶段提示和奖励倍率。第一关仍保留新手平衡：120 秒、最大怪物数 80。

关卡节奏：

- 1-27 关：90-120 秒，入门期，怪物较少，新系统逐步解锁。
- 28-54 关：120-150 秒，成型期，飞行、远程、护甲、复生和精英组合变多。
- 55-81 关：150-180 秒，挑战期，精英怪和 Boss 分阶段压力更高。

难度曲线集中在 `getLevelDifficulty(level)`，不会只靠粗暴加血；它同时控制 `hpMultiplier`、`speedMultiplier`、`damageMultiplier`、`spawnMultiplier`、`eliteChance` 和 `bossPhaseCount`。

伙伴邀请节点：

- 通关第 9 关：邀请第 1 名伙伴。
- 通关第 27 关：邀请第 2 名伙伴。
- 通关第 45 关：邀请第 3 名伙伴。

系统解锁节点：

- 通关第 36 关：开启法宝系统，并解锁第 4 个符文槽。
- 通关第 63 关：解锁第 5 个符文槽。
- 通关第 81 关：结算标题显示“九九归真，妖劫尽散”。

每个试炼独立保存最佳斩妖、最高境界、最长存活和镇守次数。通关第 N 关会解封第 N+1 关，已通关关卡可以重复挑战。

毒雾妖死亡后的毒雾只有贴近山门结界时才会腐蚀城墙，远处毒雾只作为视觉和战场压力提示，不会隔空扣血。

灵石结算仍使用原公式，再乘以当前试炼奖励倍率和取经根基收益加成：

```javascript
最终灵石 = Math.floor((斩妖数 + Math.floor(存活秒数 / 10) * 2 + 通关奖励) * rewardMultiplier * 收益加成)
```

宝石碎晶奖励会随试炼追加，越后期试炼额外碎晶越多；Boss 关还会掉落符文和法宝碎片。

## 局外成长分工

当前局外成长拆成 6 层：

- 取经根基：全角色账号成长，消耗灵石，提升山门结界、藏经心法、筋斗云路、镇妖法阵、聚灵香火、破邪真诀、妖鉴通明。
- 角色养成：孙悟空、唐僧、猪八戒、沙僧独立升级，出战获得角色经验，每 10 级需要灵石突破，最高 81 级。
- 伙伴助战：邀请来的角色只负责周期性自动助战，使用灵石升级，最高 30 级。
- 符文系统：负责流派搭配，初始 3 槽，第 36 / 63 关扩展到 4 / 5 槽。
- 法宝系统：第 36 关开启，可装备 1 个主动法宝 + 2 个被动法宝，Boss 关掉落碎片合成升级。
- 妖怪图鉴：遇到妖怪后解锁，记录击杀数；首次收录和累计击杀奖励会给灵石，受“妖鉴通明”加成影响。

灵石用途：取经根基升级、角色突破、伙伴升级、符文强化/重铸、法宝升级、局内刷新升级选项。

仙玉用途：复活一次、兑换灵石、符文重铸、购买法宝碎片箱、刷新藏宝阁。

## 仙玉系统

仙玉是稀有货币，用于救急和资源转换，不直接购买永久攻击力，也不能直接提升角色等级、取经根基等级或伙伴等级，避免和灵石、角色经验、伙伴养成冲突。

当前用途：

- 复活一次：山门失守时，如果本关尚未复活过，可消耗 30 仙玉复活，结界恢复 50% 最大生命，并清除靠近结界的部分妖怪。
- 兑换灵石：10 仙玉换 1000 灵石，50 仙玉换 6000 灵石，100 仙玉换 15000 灵石，300 仙玉换 50000 灵石。
- 符文重铸：在符文玉匣里消耗 20 仙玉，随机重铸一枚已有符文。
- 法宝碎片箱：小箱 50 仙玉，随机 3-5 个法宝碎片；大箱 100 仙玉，随机 8-12 个法宝碎片。
- 刷新藏宝阁：每次消耗 10 仙玉，只刷新推荐内容。

## 法宝系统

法宝数据集中在 `main.js` 的 `ARTIFACT_DEFS`，品质配置在 `ARTIFACT_QUALITIES`。本地存档使用 `zmsw_artifacts` 和 `zmsw_equippedArtifacts`，云存档也会同步这两个字段。

法宝第 36 关通关后开启装备功能；第 36 关前仍可从 Boss 关和藏宝阁法宝箱提前获得碎片。装备规则为 1 个主动法宝 + 2 个被动法宝。

品质和满级：

- 凡品：10 级。
- 良品：15 级。
- 上品：20 级。
- 灵品：25 级。
- 仙品：30 级。

主动法宝：

- 金箍棒（仙品）：横扫一条直线，升级提升伤害、宽度并降低冷却，满级后命中 Boss 追加震荡伤害。
- 紫金钵（灵品）：吸附范围内小怪并持续伤害，升级提升范围、持续和伤害，满级后结束时追加佛光爆发。
- 芭蕉扇（灵品）：大范围击退并造成风系伤害，升级提升范围、击退和伤害，满级后对飞妖/风系怪额外增伤。
- 紧箍咒（上品）：控制精英和 Boss，普通怪眩晕更久，升级提升控制、伤害和冷却，满级后控制期间敌人受到伤害增加。
- 照妖镜（上品）：短时间让敌人受到伤害增加，升级提升持续和增伤，满级后对精英怪额外破防。

被动法宝：

- 锦斓袈裟（灵品）：开局获得护盾，升级提高护盾值。
- 净瓶（上品）：定时回复结界生命，升级提高回复量并降低间隔。
- 火眼金睛（仙品）：提升暴击率和暴击伤害，对幻影/白骨类更有利。
- 定风珠（上品）：降低飞妖、黄风、黑风类怪物威胁。
- 镇妖铃（良品）：降低精英怪伤害，满级后精英怪靠近结界时减速。
- 紫金葫芦（灵品）：击杀概率吸取灵气，额外获得修为或灵石，满级后 Boss 关额外获得碎片。

碎片合成：

- 良品需要 30 碎片。
- 上品需要 50 碎片。
- 灵品需要 70 碎片。
- 仙品需要 100 碎片。

已合成法宝可继续消耗碎片和灵石升级。升级公式在 `getArtifactUpgradeCost()`：

```javascript
fragmentCost = Math.ceil((5 + level * 1.5) * qualityCostMultiplier)
spiritCost = Math.floor(300 * Math.pow(1.16, level - 1) * qualityCostMultiplier)
```

Boss 关为 9、18、27、36、45、54、63、72、81。通关 Boss 关会掉落法宝碎片，首通额外掉落；不同 Boss 有不同偏向池，例如第 18 关偏向定风珠/芭蕉扇，第 36 关偏向照妖镜/紧箍咒，第 81 关偏向金箍棒/火眼金睛/紫金葫芦。掉落逻辑在 `addBossArtifactDrops()`。

藏宝阁提供法宝碎片箱：

- 小法宝碎片箱：50 仙玉，随机 3-5 个碎片，偏向良品/上品。
- 大法宝碎片箱：100 仙玉，随机 8-12 个碎片，更高概率获得灵品/仙品碎片。

战斗中装备主动法宝后会在底部技能栏显示法宝按钮。冷却结束后可点击释放；暂停、升级面板期间冷却不走，2 倍速时冷却按游戏内时间推进。

## 每日挑战

首页提供“每日挑战”入口。每日挑战使用本地日期 `YYYY-MM-DD` 作为 seed，同一天生成固定主题、怪物池、Boss/精英波和限制条件。

限制条件可能包括：指定主角、符文槽减少、怪物速度提升、不能复活、技能冷却增加、Boss 血量提升。每日挑战可以重复挑战，但奖励每天只能领取一次。

完成奖励包括：

- 灵石 +1000。
- 仙玉 +20，高斩妖可额外 +10。
- 随机符文 x1。
- 随机法宝碎片 x3。

每日挑战存档在主存档和 `zmsw_dailyChallenge` 中，结算逻辑在 `SaveManager.addDailyChallengeResult()`。

## 无尽镇妖

通关第 81 关后开启“无尽镇妖”。无尽模式没有固定通关时间，结界血量归零后结算。

规则：

- 每 60 秒为 1 波。
- 每 5 波出现精英妖潮。
- 每 10 波出现 Boss。
- 难度随波数提升，支持 1x / 2x。

结算目标包括存活时间、到达波数、斩妖数和 Boss 击败数。奖励根据波数和击杀发放灵石；每 5 波有符文掉落机会，每 10 波给法宝碎片；每日首次达到指定波数会获得仙玉。

无尽记录保存在 `zmsw_endlessBestWave`、`zmsw_endlessBestKills`、`zmsw_endlessBestTime` 和主存档的 `endless` 字段。

## 青绿水墨 UI 与特效

当前视觉风格调整为“青绿水墨国风修仙手游 UI”：

- 页面主色为青绿、湖绿、玉白和淡金，整体更清透柔和，不再是暗黑厚重风格。
- HTML UI 使用玉质半透明面板、玻璃拟态、细金边、圆形玉佩技能图标和轻柔云雾背景。
- 首页、HUD、试炼选择、取经根基、升级三选一和结算页统一为青绿玉白手游面板风格。
- Canvas 绘制青绿色渐变、云雾、水波、远山、月光、玉阶山门和半透明结界感城墙。
- 背景妖气会根据 `LEVEL_CONFIG.level1.duration` 计算的进度逐步增强。
- 山门低血时裂纹更明显，受击时会闪烁。
- 怪物外观使用妖物剪影、红眼、妖气、护盾纹和国风血条表现；小妖、巨妖、疾行妖、护盾妖以及后续新增妖物都有不同轮廓和反馈。
- 5 类底层技能会按当前主角显示为不同主题：主武器、范围法术、镇妖控制、天威雷法和护山法阵。
- 命中、死亡、护盾破裂、回血、灵石结算都有粒子或文字反馈。
- 升级卡片为玉质半透明卡片，左侧圆形技能图标，稀有和史诗有不同发光表现。

背景、特效和 UI 主要使用 Canvas 几何图形、CSS 渐变、阴影和动画完成；妖怪主体使用本地原创裁切 PNG sprite，没有引用外部图片素材，也没有引入外部字体文件。

## 音效与震动

首页提供“音效：开/关”按钮，状态会保存到 localStorage 存档中。

音效使用 Web Audio API 实时生成，不引用外部音频文件。当前包含：

- 按钮点击
- 主武器命中
- 范围法术爆发
- 镇妖控制命中
- 天威雷法命中
- 城墙受击
- 升级选择
- 游戏胜利
- 游戏失败

如果手机浏览器支持 `navigator.vibrate`，城墙受击、升级选择、天威雷法命中、胜利/失败会触发轻量震动。浏览器不支持时会自动跳过，不影响游戏。

## 战斗加速

战斗界面右上角提供“速 x1 / 速 x2”按钮。2 倍速会让关卡倒计时、怪物移动、刷新节奏、技能冷却、弹道、粒子、状态持续时间、Boss 计时和区域效果都按游戏内时间加快。暂停、升级三选一、结算和 UI 点击不受影响。

速度选择会使用单独 localStorage key `zmsw_timeScale` 保存，只接受 `1` 或 `2`。

## 性能限制

- 游戏循环仍使用 `requestAnimationFrame`。
- 第一关最大怪物数量保持 80。
- 普通战斗粒子上限 250，2 倍速时收敛到 200。
- 背景灵气粒子上限 40。

## 灵石系统

- 存活奖励：`Math.floor(存活秒数 / 10) * 2`

- 通关额外获得 2 个随机宝石碎晶。

## localStorage 存档说明

## 手动云存档

游戏新增“手动云存档”功能，不需要账号、手机号或密码。玩家在“存档信息”面板里点击“上传云存档”，服务端会返回一个类似 `ZM-8F3K-29D7` 的存档码。换手机或清缓存后，在同一面板输入存档码并点击“读取云存档”，确认覆盖本地进度后即可恢复。

云存档 API：


云端存储使用 Vercel KV / Upstash Redis REST API。需要在 Vercel 项目环境变量里配置：

```text
KV_REST_API_URL
KV_REST_API_TOKEN
```

如果没有配置环境变量，接口会返回：

```json
{
  "ok": false,
  "error": "云存档服务未配置 KV_REST_API_URL / KV_REST_API_TOKEN"
}
```

GitHub Pages 只能托管静态文件，不能运行 `api/save.js`、`api/load.js`、`api/health.js` 这些 Serverless Functions。因此纯 GitHub Pages 地址仍然可以正常游玩和使用本地 localStorage 存档，但云存档会提示“云存档服务未启用，请部署到 Vercel 后使用。”朋友要使用云存档，应访问 Vercel 部署后的游戏地址。

```bash
vercel
```
